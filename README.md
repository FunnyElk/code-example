## Создание объекта

Один E2E тест из рабочего набора

### Стек

* TypeScript
* Playwright

### Структура

Сценарий создания объекта и связанные с ним helpers

```text
tests/
  create.object.spec.ts       # сценарий создания объекта для трёх ролей
  helpers/
    auth.ts                   # вход и выход
    create.object.ts          # создание объекта
    objects.ts                # навигация и проверки объекта
    ui.ts                     # общие UI-утилиты
```

### Пара нюансов по коду:
* **Архитектура**: Выбрал хелперы вместо классов (POM), чтобы не раздувать бойлерплейт. С ленивыми локаторами Playwright это работает отлично.
* **Воркаунды**: В коде есть `page.reload` в цикле и `.catch` на кликах. Это вынужденное решение: создание объектов шло через асинхронную очередь (приходилось ждать появления карточки), а анимации Ant Design иногда перехватывали клики.
* **Локаторы**: `data-testid` на проекте не было, поэтому завязался на текст и относительные пути.
